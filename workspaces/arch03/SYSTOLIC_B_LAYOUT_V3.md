# B/v3无损加载格式

layout为`0x00100003`，Q12、shift、舍入和饱和不变。编码器`systolic_b_codec.py`接收已验证的46976字节tile16原始流，不读取或更改模型。软件恢复检查独立按X(row,k)、W(k,column)、bias(column,part)核对23488个半字，不仅使用正反重排。

## 流与头

所有字段小端，段边界按32位对齐。解码输出依次为W0的1024个半字及48个偏置半字，X的99×64个半字，再W1/bias1至W15/bias15。偏置保持low16、mid16、high8加8位零填充。

全局头32字节，八个32位字段依次为`0x3343574b`、`0x00030000`、`0x00100003`、flags、含头总字节数、23488、46976、0。flags仅允许0或1；1表示整流raw，固定47008字节。raw仍按新流顺序排列。所有输入通过真实32位ICB，成功共享写ACK后才交解码。

## 权重tile

每tile先一个32位模式头，再权重载荷，最后96字节原偏置。模式头必须完全等于0、1、2之一：

| 模式 | 权重载荷 | 完整tile字节数（含偏置） |
|---|---|---:|
| 0 raw | k→lane的1024个signed16 | 4+2048+96 |
| 1 block | 16个v2块，每块64元素，保留原块头 | 4+各块完整长度之和+96 |
| 2 column | 8字节列位宽表，再k→lane位流 | 4+8+8×各列位宽之和+96 |

列宽表为16个小端顺序四位数，第lane个值为width−1，支持1至16位。有符号值低width位按k→lane、低位先行写入连续位流；不能改成整列连续，否则宏写入顺序改变。旧块头width位于[4:0]，固定count−1=63位于[10:5]，其余为0。

## X行

每行一个32位头再64元素载荷。头[1:0]为模式，[6:2]为width，[15:7]必须0，[31:16]为有符号base。

| 模式 | 要求 | 载荷 |
|---|---|---|
| 0 signed | width=1..16，base=0 | 有符号width位 |
| 1 delta | width=0..16 | 无符号差值，恢复为base+delta；必须在signed16范围 |
| 2 raw | width=16，base=0 | 原signed16 |

模式3非法。delta取base=min(row)、width=bit_length(max−min)，常量行width0只有头，仍必须产生64个元素。各行完整长度4+8×width字节。输出越界不得回绕。

编码器对每个tile/行比较全部模式的完整长度。相等时权重选raw→block→column，X选raw→signed→delta，优先简单解码。全部段加头若不比原始载荷小，整流raw回退；保证总输入≤47008字节。头、表、偏置和对齐均计入比较。

## 当前证据边界

8项软件定向测试通过，包含全位宽、常量、极值、跨字、三种权重模式、头错误、截断、delta越界、偏置填充及raw回退。14个实际测试输入恢复23488半字逐坐标一致。12层平均31338.6667字节，相比v2约37.1KB减少；首块前缀1672至2184字节。

保留共享写入的理想事务下界平均为`31338.6667/2+12672=28341.3333`，未计协议及计算空隙，不能作为实测吞吐。RTL独立解码器25种情况通过，包括14例数据、全模式、强制raw、9种坏流；每个正常流取消重启后无复位执行两次，187拍长反压。运行目录`local_runs/systolic_b_decoder_20261111_203643_913485`，详见`handoff/team/evidence/SYSTOLIC_B_CODEC_V3_20261111.json`。
