# C32-A两行脉动接口

从冻结C80派生，独立硬件身份，当前处于本地验证阶段。

| 字段 | C32-A |
|---|---|
| MMIO 0x000硬件ID | `0x4b57530d` |
| MMIO 0x074能力 | `0x000b02bf`：版本11、2行 |
| MMIO 0x08c数值 | `0x000e0c20`、SHIFT10 |
| 编码布局 | `0x00100006`，完全复用C80文件与解码器 |
| 阵列/结果区 | 2×16 PE、两组32项结果、32路转换 |
| 块身份 | 10位，50行对×16列tile＝800块 |
| 内部存储 | 60个X＋32个W的128×16宏，容量23KiB |

编码布局与阵列布局分别声明：编码仍按逻辑矩阵定义，与PE行数无关；新的硬件ID、能力及固件行数2声明阵列变化，固件拒绝5行硬件或不匹配身份。不默默改变C80头格式。

MMIO偏移、IRQ/WFI、取消、错误及排空语义保持。源信用3、事务元信息深度2、源/读回FIFO16、输出FIFO32、描述符8和原平台总线参数保持；源读取→共享写成功ACK→原ICB读回→解码→计算→输出写ACK全部实际执行。最大编码长度46496B、内部23488半字和25344输出不变。

每个tile共50个两行块，最后只计算row98；row99不读取、不累加、不输出。物理X仍按row%5和k%4分bank，读取流水保存实际物理bank/组及逻辑块号。块到齐独立按行对发布；冲突逐物理宏仲裁。

X14/W12/乘积26/累加32/偏置32/total33/result16、SHIFT10及半值远离零保持。数据和标签同步暂停，最后乘积计入总和。最终DONE仍等最后成功写响应和事务排空。

本地阵列和替代宏通过不代表真实E203、厂商宏、综合、门级或功耗通过。C32使用自己的运行目录与证据；冻结C80/T80均不改变。
