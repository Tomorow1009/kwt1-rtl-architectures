# T80后续路线最终报告：S0 → P80 → C80 → C32-A → G32

本轮选定并冻结 **G32：16列×2行、32 PE脉动阵列＋实际时钟门控**。约定前20条语音的验证、完整PPA、独立模型审阅及持久备份均已完成。冻结索引为[G32_FREEZE_20261117.json](../../handoff/team/evidence/G32_FREEZE_20261117.json)，标签`arch03-g32-final-20261117`。服务器桌面T80交付和全部旧八路数据保持原样。

## 实现的路径

1. **S0：**CPU/SoC、共享SRAM、加速器分别综合并顶层链接，统一跨块约束、库与负载；面积按实例归属和保守未决归属分别报告。DDC只在依赖指纹一致时复用，不凭文件名复用。历史综合恢复耗时不包装成冷启动加速倍数。
2. **P80：**DMA及团队仲裁使用有序事务信息队列、CPU/DMA响应归属和完整信用管理。深度2/4/8实测完整周期相同，选择最小深度2；源信用保持3，不改变原平台缓冲参数。失败写不发布共享读依赖，取消后排空已接受事务，最后输出ACK才完成。
3. **C80：**软件筛选后冻结格式`0x00100006`，加入预测/精确残差、有界Rice及raw回退，偏置用两个半字。格式与MAC行分组解耦，完整固定12编码均值从29,756B降到25,790B（减少13.3284%），并以实际完整周期确认收益。
4. **C32-A：**阵列改为16×2，50个行组×16个列tile，末组仅row98有效；缩减偏斜、累加、结果和转换路径，保留完整X缓存。原映射曾有326条transition违反，最终使用同库6个等价驱动修复；旧失败不被覆盖，新网表重新完成门级、活动与功耗。
5. **G32：**实际383个`CLKLANAQV4_12TR40`门控数值数据寄存器，控制、valid、信用、响应、IRQ及取消继续运行。实际覆盖10,306个寄存器时钟端点，逐个766项门控setup/hold核对通过；SRAM保持原片选/写使能，CPU保持真实IRQ/WFI。

全程保持原32位ICB、原平台参数、X14/F10、W12/F12、32位累加/偏置、33位total、16位/F12结果、SHIFT10及原舍入饱和。输入经过源读取、实际共享写成功ACK、原总线读回和解码；输出完整写回共享SRAM。不旁路共享存储、不压缩输出、不跨任务预装载。

## 保留但未采用的探索

- C32-B尝试两个4096×16 X宏，奇偶行分bank并处理单端口争用。本地十四例正确，但所比任务合计周期从725,798增至726,236，吞吐下降0.06031%；按“不降低吞吐”规则未晋级，也没有冒用C32-A的面积或功耗结果。
- G32首次PT查询因工具不支持pin的name属性而失败；只修正三处查询为full_name，硬件、网表和约束未改。原失败、外部恢复和正常复现入口均保留。
- 未恢复宽ICB、共享写ACK旁路、A广播版、旧T64/G64或其他数值格式路线。
- 共享盘满时，新作业产物写/tmp；只处理已完整归档核验的生成重复件，并对R4 L03/L04波形无损转换、完整解压回验和持久归档。没有删除旧八路或桌面T80。

## G32验收与限制

G32自身完成10,000个随机计算块及定向边界、真实ASIC/E203十四例、恢复和CPU竞争、前20条×12层240任务。6,082,560个输出及total逐项相同，零失败；同网表功能门级十四例354,816输出、十二层完整SAIF与PT均完成。20条逐层最大NRMSE为0.2019814384%，逐任务最大0.2095340893%，裁剪/饱和0。

150MHz声明任务模式setup +0.000433922ns、hold +0.00289777ns；门控setup +0.070571ns、hold +0.18723ns。220个宏、无非预期锁存器、设计约束无违反。保守项目面积满足1.00mm²，0.50mm²努力目标未达到；整机4.2501888471mm²包含复用存储，不能当作项目面积。

实测2078.1572task/s未达到接近3000的目标。两行分块计算下界51,200周期，25,790B编码下的条件搬运预算约70,476.5周期，实测72,179.3333；有效MAC利用率70.2251%，主要限制仍是完整搬运与供数。详细阶段和等待统计见[G32阶段报告](G32_STAGE_REPORT_20261117.md)。

功耗覆盖同网表E203、互连、相关SRAM和加速器，按完整窗口时间加权；未将未知活动、缺模型或驱动内部功耗视为零。未知名称和关键端点、静态JTAG、禁用弧及实际时钟已审阅，结论限定为稳定任务模式与布局前估算。门级没有SDF；官方600条、布局后时序功耗及物理签核不在本轮结论中。
