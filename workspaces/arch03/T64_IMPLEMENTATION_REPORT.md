# T64实现与当前验证边界

基于冻结T80数值和搬运实现，将计算从5×16改为4×16输出驻留脉动阵列。T80生产文件不变，新入口为`arch03_t64_accel`、`arch03_t64_linear16x4`、`arch03_t64_systolic4x16`。当前只完成本地验证，尚无T64服务器功能或PPA结论。

## 实现

- X仍为60个128×16宏，保留五行物理映射；W仍32个宏、物理双缓冲。四行窗口的基行每块递增4，并将五行物理组/行bank标签随SRAM响应流水保存。
- 99行分25组，最后只处理96～98行。物理读请求按实际宏解决装载冲突；响应队列仍为READ_LATENCY+2。绝对行坐标核对覆盖240次跨五行组窗口/任务。40行宏段边界与四行计算组对齐，因此不存在跨宏段的单个四行窗口，边界前后读取仍逐坐标检查。
- 64个PE复用未改变的signed14×signed12、signed32累加和signed33偏置求和，SHIFT10。结果槽改为2×64项，末块等待48项；相邻结果双交接和32字输出FIFO不变。
- 直接实例化同一`arch03_t80_transport`；源读、共享写、共享读、输出写四类事务及成功写后才可读的规则不变。没有新增ICG。
- ID为0x4b575309，能力0x000804bf，layout 0x00100004、numeric 0x000e0c20。新增独立IRQ固件、诊断固件、SoC/前20条/门级/SAIF/PPA工具；这些服务器入口仍待实际运行验证。
