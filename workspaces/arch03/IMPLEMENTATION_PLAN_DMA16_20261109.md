## 3. 加载与ICB集成

优先恢复原sysmem_icb_*加载源接口。当前安装器将它绑零；实施首项须查比赛固定平台原始上层接线、地址译码和响应端，确认加载环境接入方式。源地址只取原译码内未占用范围，冻结到manifest，不默认新增任意外部加载口或SRAM私有端口。

完整通路：PC预读/量化重排→原SysMem ICB源读取→DMA写512KiB共享SRAM→DMA从共享读取到X/权重缓存→16路MAC→结果FIFO→DMA写回共享SRAM。

- ITCM初始镜像只含程序和真正静态软件数据，不预填任务输入或权重。
- 性能源模型为32位同步ICB、单笔在途、接受后下一拍响应；各对照统一条件。PC/TB只预读文件并响应真实请求，不能force存储。
- 输入先成功写入共享，再从共享读到加速器；不直接源旁路MAC。只有成功写响应推进已提交水位。
- 保留已有共享SRAM时序；CPU/DMA公平仲裁，首版单outstanding。实测源读、共享读写、切换和竞争服务，不把NICE6周期数字当本通路实测。
- 同一任务内可重叠加载、预取、计算、写回；不提前加载下一任务，每次任务失效内部缓存。
- 有效字节包含源读46976、共享入库46976、共享读取46976、结果写回50688，共191616B/任务，另计协议等待。
- 规划估算16路源读3周期/字、共享写2周期/字时串行约227008周期，不是达标证明。

## 4. 16路核心、布局和接口

独立新增架构三16路模块，不破坏架构二和现有8路模块。实例化16路原dot64，数值规则不变。

- X：2个4096×16宏，共16KiB，每任务装入一次后广播。
- W：32个独立128×16宏，即16lane×2bank，共8KiB，计算bank与装载bank物理独立；不能靠单端口宏地址分区假装并行。
- 每bank维护valid、tile_id和bias[16]；W/b完整才发布有效。加载与计算分别控制，先关闭预取调试，再打开bank轮换。
- 输出FIFO为16条32位记录，容纳2个tile行，保存地址和饱和信息，满时反压，写完成只按成功响应统计。
- 布局：X6336半字行主序；16tile，每tile W64×16按k→lane，共1024半字，bias16×3共48半字。两个半字低半字先行小端打包；总46976B。输出25344个int16行主序，总50688B，行跨度512B。
- 独立按原矩阵坐标验证每个重排元素，不用同一排列函数往返自证。记录模型来源、量化尺度/舍入/饱和、索引、tile序、字节序、对齐和哈希。

保留原0x00—0x20 MMIO地址作调试入口，新增版本/能力和任务级源地址、输入/输出地址长度、layout、shift、启动/取消、BUSY/DRAINING/DONE、错误地址/阶段、中断使能/锁存W1C、提交/完成/饱和计数。首版固定矩阵尺寸，4字节对齐，配置只在idle写，启动整体锁存，检查越界、溢出及重叠。

DONE条件：全部输出成功写响应完成、FIFO空、所有相关事务排空。取消/错误停止发新请求，保持已发valid请求稳定、排空已接受事务后再清核心；不能丢弃owner，已接受写不可撤销。

E203通过平台中断控制器真实IRQ处理和WFI等待，验证唤醒/超时恢复。宏片选、寄存器使能、操作数保持降低活动；无实际活动/功耗证据不宣称节能。
