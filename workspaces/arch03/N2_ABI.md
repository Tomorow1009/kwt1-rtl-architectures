# N2 数值与固件接口

独立版本 ID `0x4b575307`，能力寄存器 `0x074=0x000605bf`，数值身份只读寄存器 `0x08c=0x000e0c20`。沿用B0的原32位ICB、MMIO寄存器、DMA、IRQ/WFI与取消排空语义。新固件在任何任务前同时检查以上三个身份；B0入口不修改。

N2只支持layout `0x00100004`、SHIFT=10、五行×16列。X signed14/F10、W signed12/F12、乘积26/F22、累加与偏置32/F22、total33/F22、输出16/F12。舍入半值远离零并饱和signed16；绝对值与舍入临时量34位。

装载保留16位容器、23488个半字和三半字偏置。偏置32位符号扩展到40位后，第三半字为0000或00ff，高8位必须0。N2保留B0 v3压缩算法、32字节头和W0/b→X→W1…顺序，头word2为新layout、word7为数值身份。非法扩展、旧头、错误SHIFT明确拒绝。

启动参数位于固件ITCM 0x8000fff0的四个32位字：SHIFT10、编码字节数、layout4、行数5。0x80010000以后不允许预填任务输入；数据经原SysMem ICB源读取、共享SRAM实际写ACK后才解码。共享输入0xa0000000，输出0xa000c000，输出25344个16位结果/12672次32位写。DONE仅在最后成功写ACK且事务排空后发布。

本文件描述实现契约，不是功能、PPA或官方精度通过证明。N2使用自己的运行目录和证据。
