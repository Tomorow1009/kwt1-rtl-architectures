# 完整任务性能基线

本记录是功能仿真中实测窗口的换算，不是已经满足时序的最终参赛成绩。绑定旧 UART 配置：ASIC RTL `46cb3de/d3_full01`、原始整机映射 `c323781/d3_synth03`、报告复核 `4c8803e/d3_reports01`、门级首层 `4c8803e/d3_gate01`。输入/固件及摘要指纹见 [服务器证据](../../handoff/team/evidence/UNDERGRAD_D3_SERVER_20261109.json)。

| 指标 | 数值与依据 |
|---|---|
| 每任务形状 | `99×64 × 64×256 → 99×256`，含偏置、转换及全部结果写回 |
| 完整窗口 | 3,890,080 周期，从 BEGIN 标记成功应答至最后结果成功写应答 |
| 实际时钟周期 | 6.666666 ns |
| 完整任务时间 | 25,933,864.073280 ns = 25.933864073280 ms |
| 完整任务吞吐 | 38.5596221672 task/s |
| 输出吞吐 | 977,255.064204 元素/s；每任务 25,344 个输出 |
| 等效乘加吞吐 | 62,544,324.1091 MAC/s；每任务 1,622,016 次乘加 |
| CPU 自报周期 | 3,890,176，比被动窗口多 96 周期；两种计数不混用 |
| 任务装载量 | 23,488 个 16 位输入/参数字，46,976 字节 |
| 结果写回量 | 25,344 个 16 位输出字，50,688 字节 |

ASIC RTL 全部 14 个独立任务的窗口一致；已验门级第 1 层相同。总线监视器记录共享内存侧 23,488 次读、48,832 次写，命令/应答等待计数均为零。这些不是整系统 SRAM 总访问数，不能直接用来代替功耗活动。

计算式为 `task/s = 1e9 / (周期数 × 周期_ns)`。单任务能耗须使用同配置、同窗口的实际系统平均功耗：`E_J/task = P_W × 0.02593386407328`。目前没有通过审核的 P_W 数值，因此不填入能耗，也不使用核心 START/DONE 的短窗口替代上述时间。

旧映射 setup −1.77329254 ns、hold −0.09681505 ns；时序未通过。新 UART/任务模式修正配置需要重新测量，不能沿用这里的面积、功耗或性能作为新配置已通过的证据。只有必做验收完成后，才进行 PR #6、32 位复制等同条件对照。
