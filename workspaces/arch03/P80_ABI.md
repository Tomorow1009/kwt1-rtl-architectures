# P80原32位ICB有序事务队列接口

状态（2026-11-16）：本地协议及数值、三种深度各真实ASIC/E203十四例、深度2恢复/竞争和前20条240任务已通过；独立新综合正在进行，整机PPA及阶段验收未完成。原T80入口不修改。运行身份和入口见[P80复现说明](P80_RUNBOOK.md)。

数值身份`0x000e0c20`、布局`0x00100004`、SHIFT10、五行80PE、编码与加载顺序均保持。原MMIO偏移和启动/取消/错误/IRQ语义不变；保留完整输出与成功共享写ACK后真实总线读回。

| 偏移 | 只读内容 |
|---|---|
| 0x000 | P80硬件ID `0x4b57530b` |
| 0x074 | 能力/ABI身份 `0x000905bf` |
| 0x08c | 原数值身份 `0x000e0c20` |
| 0x090 | 本次编译的事务元信息队列深度2、4或8 |
| 0x094 | `[3:0]` DMA已接受未返回数量，`[7:4]`本任务峰值，其余零 |
| 0x098 | 等待元信息信用、尚未呈现下一请求的周期数；与其他停顿可能重叠 |

固件同时检查ID、能力、数值身份及预期队列深度，旧T80固件不被静默接受。队列深度是硬件配置，不是运行中可写寄存器；新任务开始时清零高水位和信用停顿计数。

仲裁器归属按成功命令握手入队、响应握手出队；CPU公平性按已接受请求轮转。DMA同样按有序响应队首核对类型和地址，取消时保持已呈现请求并排空已接受事务。新增队列不改变源信用3、源/读回FIFO各16、输出FIFO32、原描述符队列8或平台总线参数。

正式时窗从首源VALID至最后DMA输出成功写响应，随后确认队列/FIFO排空。固定12性能任务、正式前20条240任务及每个新网表的门级/活动/PPA分别绑定。当前固定12的平均周期为77,545.3333333；240任务零差异，其平均周期77,545.1583333单独记录。不能将这两组ASIC RTL结果当作新网表PPA通过。
