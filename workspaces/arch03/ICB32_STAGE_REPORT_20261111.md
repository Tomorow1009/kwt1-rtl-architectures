# 架构三本轮实现与探索总结

2026年11月11日收尾。用户要求先报告、保存和同步本版，之后提供新的目标与计划；现有远端功耗作业保留，暂不启动剩余队列或新架构。提交入口与署名暂不急；用户确认没有额外存储空间。

## 本轮结论

当前交付候选为 **原32位ICB＋无损输入编码＋共享写成功ACK后转发＋16列×4行MAC＋物理权重双缓冲＋E203 IRQ/WFI**。该候选自己的1200个真实ASIC RTL/E203任务全部通过，共30,412,800个输出，零失败。最终同配置报告和源码交付准备包已经生成，现有664 task/s版本保留作退路。

本轮取得约4333 task/s，未达到5000。相对原16路DMA基线，完整流程吞吐提高6.522倍、单任务能耗估算降低62.84%；平均功耗增加，不能说功耗和能耗都降低。所有吞吐均按仿真周期和150MHz折算，功耗为综合网表布局前估算，不是芯片实测。

## 实际实现了什么

1. **搬运真实计时。** 原SysMem 32位接口读取输入，经ICB DMA写512KiB共享SRAM，成功写ACK后才允许解码和消费。保留真实落库，省掉重复读回；不预装下一任务。错误响应不发布数据，取消后排空已接受事务，DONE等待最后输出ACK。
2. **离线无损编码。** 原Q12数值、模型、bias、shift、舍入、饱和均不变。PC按tile重排，对64元素块选择最小有符号位宽，明确头格式、小端顺序和对齐；压缩无收益时raw回退。硬件进行有界缓冲解码和格式检查，输出仍为原16位行主序。
3. **64个MAC并行。** 复用原dot64，组织成16列×4行；权重向4行广播，X分bank但不复制整份。99行尾组屏蔽无效行；32个权重小宏构成两个物理bank，完整权重及偏置到齐后才发布有效。
4. **同任务流水与反压。** 源/提交缓冲、命令队列、两个结果bank和32条输出FIFO；同拍退旧响应/接新命令分别跟踪归属；CPU公平仲裁。预取、计算和写回能够重叠，FIFO满时停住，不覆盖未提交结果。
5. **保留SoC与异常恢复。** E203负责配置、IRQ/WFI等待和异常处理。真实CPU竞争、无复位A/B/A、取消、超时恢复及错误路径已验证。宏片选和操作数保持用于控制活动，未把未经测量的节能推断写成结果。

共享ACK转发和编码流落库是团队依据赛题答疑所作的工程解释；答疑确认真实传输和允许离线量化/重排/打包，并未逐项确认本实现，材料中保留这一边界。

## 探索过的路径与取舍

| 路径 | 取得的结果 | 本轮处置 |
|---|---|---|
| 原8路MMIO/E203逐字调度 | 真实ASIC及完整14例功能门级、12活动通过；每任务3,843,121周期 | 保留原始对照。新全14gate对应L01功耗19.939132mW、510.856595µJ；其余未齐，不能当12层均值 |
| 原16路DMA、共享写后读回 | 完整四段搬运；225,770周期、664.393task/s；12层29.6273mW、44.5931µJ；自己的1200任务通过 | 保留已验证退路，不用后来的硬件继承其PASS |
| 64/128位数据侧、C128设想 | 四段公共32位通路每任务47,904事务，证明只加MAC不足以达到5000；宽通路仍需平台框架确认 | 仅分析，没有接入正式SoC；后续按用户新计划改用32位方案 |
| B1：16路＋原始输入ACK转发 | 本地14例抖动和6例nominal验证；代表性prefetch开启周期162,713 | 作为局部探索保留，没有独立完整服务器PPA，不与最终结果拼接 |
| R1：16 MAC＋新编码/搬运/缓存 | 独立真实ASIC14例354,816输出通过；12层116,280周期、1289.990task/s；综合面积保守上界0.618655mm²，setup/hold为正 | 同搬运对照成立；自己的门级/功耗未做，磁盘预算不足且没有额外空间，暂缓 |
| R4：同通路改为16×4 MAC | 同逻辑输入平均34,616周期；R1→R4实际CPU周期加速3.359140倍 | 本轮交付候选，已完成自己的1200、门级/活动及12层功耗数值 |
| 固定R4，只改raw/编码 | 本地12层304,128输出一致；38,052→34,616周期，减少9.03%；事务减少13.69% | 支撑编码的局部贡献；无CPU/PPA，不据此推算能耗 |

实际CPU完整周期链为 **225,770 → 116,280 → 34,616**。前一段1.941606倍包含搬运、编码、缓存和调度共同变化；后一段3.359140倍是同一新通路下的行并行变化。不能把总6.522倍全部归因于MAC或压缩中的单独一项。

当前12层平均编码37102.667B，约需31223.333个32位事务，已经超过5000task/s所允许的30000周期。当前格式与事务组织存在带宽下界；不缩短统计窗口、不漏算装载、不跨任务预载来改变结果。
