# G32两行脉动及实际门控接口

从冻结C32-A派生，使用独立硬件身份；已完成本计划前20条验证及声明条件PPA，并冻结为`arch03-g32-final-20261117`。证据范围见`G32_STAGE_REPORT_20261117.md`。

| 字段 | G32 |
|---|---|
| MMIO 0x000硬件ID | `0x4b57530f` |
| MMIO 0x074能力 | `0x000d02bf`：版本13、2行 |
| MMIO 0x08c数值 | `0x000e0c20`、SHIFT10 |
| 编码布局 | `0x00100006`，复用C80/C32文件和解码器 |
| 阵列/结果区 | 2×16 PE、两组32项结果、32路转换 |
| 块身份 | 10位，50行对×16列tile＝800块 |
| 内部存储 | 60个X＋32个W的128×16宏，共23KiB |

MMIO偏移、IRQ/WFI、取消、错误及排空语义保持。源信用3、事务元信息深度2、源/读回FIFO16、输出FIFO32、描述符8和原平台总线参数保持。源读取→共享写成功ACK→原ICB读回→解码→计算→最后成功输出写ACK排空；最大编码长度46496B、内部23488半字和25344输出不变。

保持X14/W12/乘积26/累加32/偏置32/total33/result16、SHIFT10及半值远离零舍入。最后行组只计算row98，row99不读取、不累加、不输出。

数值寄存器使用库ICG `CLKLANAQV4_12TR40`。正式READ_LATENCY=1实际映射383个新增ICG，覆盖10306个寄存器时钟端点。控制、valid、归属、IRQ、响应和取消使用原时钟。`ICG_BYPASS`是综合/仿真的静态参数，生产为0，旁路测试为1；TE不在任务中动态切换。SRAM时钟不修改。

本地门控模型和替代宏结果不代表真实E203、厂商ICG、综合、门级、时序或功耗验收；G32使用自己的运行目录与证据，冻结C32-A/C80/T80均不变。
