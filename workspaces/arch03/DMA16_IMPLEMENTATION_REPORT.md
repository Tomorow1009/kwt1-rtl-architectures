# 架构三 DMA16 实施与证据报告

更新日期：2026-11-09。本文为实施中的中文报告，**不是最终合格声明**。实时证据以 [交接记录](../../CONTEXT_HANDOFF.md)、[执行检查点](EXECUTION_CHECKPOINT.json) 和 [DMA16证据清单](../../handoff/team/evidence/DMA16_IMPLEMENTATION_20261109.json) 为准。有效要求为 [三天计划](IMPLEMENTATION_PLAN_DMA16_20261109.md)，提交期限由用户补充为11月13日晚上；具体时刻未确认，内部交付仍定于11月12日17:16。

## 1. 实现目标与冻结来源

当前已实现独立16路定点MAC、任务级ICB DMA、权重物理双bank及输出FIFO，复用原8路工程的数值规则、dot64、共享SRAM时序、真实TCM适配及标准单元绑定。原8路实现保留作对照和保底，不开发8路DMA。

首个实施提交为 `2bd6b0f0075d7e0a61809cd7f70fc990e7364e85`，已同步团队私人分支。首包 `light-light126-dma16-smoke-dma16-20261109_185450-2bd6b0f0075d.zip` 共573项输入、16,217,831字节，SHA256为 `6bd72b192968bfd5783248e5978a2223f476e7b43717183df43583337d0e4a17`。本地、开发板、比赛服务器长度及哈希一致，安全解包和全部输入核验通过。后续MMIO8参考、门级、功耗和CPU恢复工具尚在工作区，不能算入该首包。

本设计完成一次 `99×64 × 64×256 + bias`，全部25,344个结果写回才算完成。每任务1,622,016 MAC；150MHz下300,000周期对应500task/s。首包真实ASIC RTL/E203首层已测得225770周期；150MHz时序、面积、全量功能和功耗尚未通过，不能据此声明最终ASIC达到500task/s。

## 2. 原平台集成与真实加载

已核对固定平台的原O4译码：base为0x80000000、region LSB为31；0xb0000000源窗口位于其覆盖范围。原SoC顶层SysMem空响应接线恢复为同一原ICB接口的完整请求/响应信号，不新增SRAM私有端口。安装器先核对163项原平台文件，基线指纹为 `ee8bfecd81e192a974be81479ef8a01793de3e59c2e2f8769886e8e86143e56e`，只修改新副本。服务器首次安装预检通过9项修改，尚不代表CPU执行通过。

```text
PC文件预读、Q12转换和tile16重排
        ↓ 原SysMem ICB源响应
DMA源读取 → 原ICB仲裁/译码 → 512KiB共享SRAM写响应
                                      ↓ 共享SRAM再读取
                           X缓存 / 两个物理权重bank
                                      ↓ 16路原dot64
                           结果FIFO → DMA共享SRAM写回

E203：配置、启动、真实IRQ/WFI或调试轮询、错误与取消恢复
```

源模型采用32位同步ICB、单笔在途：边沿N接受，寄存响应，最早N+1完成响应握手；反压时保持响应。程序启动镜像仅含代码和配置元数据，0x10000之后任务数据区域全零。PC/TB参考结果仅供被动观察器比较，不写入计算路径。

| 环节 | DMA16实际事务数 | 有效字节 |
|---|---:|---:|
| 原SysMem源读取 | 11,744 | 46,976 |
| DMA将输入/权重/偏置写共享SRAM | 11,744 | 46,976 |
| DMA由共享SRAM读取到内部缓存 | 11,744 | 46,976 |
| 结果写共享SRAM | 12,672 | 50,688 |
| 合计 | 47,904 | 191,616 |

首版先完成该任务的源到共享初装载，再在共享读取、双bank预取、计算和结果写回间重叠。只在共享写响应成功后推进提交水位。没有将下一任务预装载隐藏在当前任务窗口内。

## 3. 数值、布局与资源

不训练、微调或改变模型。输入/权重保持16位，bias、累加、移位、舍入和饱和规则复用既有数值核心；完整定义见 [数值格式](NUMERIC_FORMAT.md)。每个输入矩阵按行主序存放，权重按16个tile顺序排列，每tile的权重为k优先、lane其次；每tile末尾16个偏置，每个仍采用三半字编码。两个半字按小端组成一个32位传输字。结果保持99×256行主序、512字节行跨度。

重排工具逐个按照原始矩阵坐标独立核验，不以同一排列函数往返作为证明。14用例的354,816个整数结果与原参考逐位一致；内部600样本/7,200任务的历史软件评估最差层NRMSE为0.14941871%，不是官方精度成绩。

| 新增加速器资源 | 实现 |
|---|---|
| X缓存 | 两个4096×16宏，分配16KiB，每任务重装 |
| 权重双bank | 16lane×2bank独立128×16宏，共32宏、分配8KiB |
| bias与bank状态 | 每bank保存tile编号、有效位及bias，完整到齐才可用 |
| 计算 | 16个原dot64，X广播 |
| 结果缓冲 | 16条32位FIFO记录；满时反压，最后入FIFO不等于任务完成 |
| 互连 | CPU/DMA公平仲裁、单outstanding、响应owner跟踪 |

新的DMA、仲裁、译码、接口、FIFO及内部SRAM都计入2.00mm²预算。复用E203、TCM、512KiB共享SRAM及原固定模块另列；功耗仍包含复用模块。当前尚无DMA16实际综合网表面积，不能引用旧版本约2.05mm²情景替代。

## 4. 完成、取消与中断

配置在空闲时写，START整体锁存；检查既定尺寸、4字节对齐、地址溢出、越界及输入输出重叠。每次启动先PREPARE清空X/W有效状态，再允许首个源请求。

DONE要求最终输出成功写响应、FIFO空、所有相关事务排空及计算完成。取消/错误不撤回已发VALID或已接受写；停止新事务，保持当前请求，排空已接受事务后回到可启动状态。首次错误地址、阶段及提交/完成计数保留供软件检查。

原PLIC16个输入均已分配，DMA与原GPIOB线OR接入，保留GPIOB；实际claim ID为16。IRQ固件带真实trap、PLIC claim/complete、W1C及WFI；CLINT地址已经核对，但实际E203唤醒、timer频率和节能效果尚待运行验证。禁止仅凭WFI指令存在声明功耗降低。

新增无复位验证固件规划一次运行五项非法START访问异常、装载中取消、短timeout排空恢复，再完整A/B/A。CPU真实异常及全部回执仍需新ASIC运行，不沿用旧功能TCM序列的通过记录。

## 5. 测量口径及已有证据

统一窗口从首个源读VALID发出开始，包含首次READY等待；到最后输出成功写响应结束。排空证明可以稍后取得，但不能将其与末ACK混成不同计时终点。CPU周期用于交叉核对；WFI期间不可假设CPU mcycle与自由运行系统时钟相同。各阶段重叠跨度不能相加当总时间。

## 6. PPA与最终交付缺口

统一工艺为SS、0.99V、125°C，工具周期6.666666ns。新的恢复SysMem端口采用相同HF时钟1ns最大/0ns最小接口预算，输入转换0.1ns、输出负载0.01库单位；这些是明确接口假设，外部接收器物理规格尚未独立签核。沿用四个已审查timer首级CDC例外，不给SysMem新增false path。

新门级入口根据同SHA mapped.ddc只读探测实际模块端口，缺失则停止；最终FIFO/计算/排空证明来自末ACK之后的新MMIO响应，不把内部状态常量绑定成“空”。功耗入口必须使用相同网表、固件和完整活动窗口，审查工具错误、单位、未知值、活动映射、SRAM条件泄漏、导线与时钟模型。未完成的功耗用null，不填零。
