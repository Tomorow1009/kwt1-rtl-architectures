# C80无损编码接口

开发中，尚未正式验收。从已冻结P80深度2派生；旧P80源码和服务器包保持。C80只改变外部编码和解码器，80PE、原32位ICB、源信用3、元信息队列2、源/读回FIFO16、输出FIFO32、描述符8及全部物理缓存保持。

| 字段 | C80 |
|---|---|
| MMIO 0x000硬件ID | `0x4b57530c` |
| MMIO 0x074能力 | `0x000a05bf` |
| MMIO 0x08c数值 | `0x000e0c20`，SHIFT10 |
| 布局 | `0x00100006` |
| 最大输入字节 | 46496，含32字节全局头 |
| 内部装载半字 | 23488 |
| 外部raw半字 | 23232，偏置用两个半字 |

原寄存器偏移、IRQ/WFI、取消排空、错误归属和最终写ACK后DONE保持。固件同时检查ID、能力、布局、数值及队列深度，拒绝旧固件或旧编码身份。源读取、共享写成功ACK、原总线共享读回和结果写回四段全部实际发生。

编码细节见[C80格式说明](C80_CODEC_FORMAT_20261116.md)。解码器使用128位位缓冲和64×14前行预测状态；每次最多向原装载器交付一个16位半字。逻辑八行预测组与五行PE分组无关。紧凑b32在内部恢复第三半字0000/00ff，不增加外部事务。

描述符、位宽、Rice参数、raw符号扩展、重建溢出、padding、截断及多余字节均检查。解码器错误码：1长度，2全局身份，3块描述或表，5填充/最终计数，6截断，8数值范围。反压时输出稳定，取消后旧预测状态不可访问；每个新逻辑组首行禁止前行预测。

自身ASIC/E203、240、门级和PPA尚未运行。独立解码器与本地共享SRAM替代模型测试不能当作真实CPU或厂商宏验收。
