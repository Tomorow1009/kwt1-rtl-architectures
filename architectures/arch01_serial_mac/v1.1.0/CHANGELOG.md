# v1.1.0 与 v1.0.0 的区别

日期：2026-11-06。上一版本所在提交：`aec0c4136ff0aa9630e1838e5cea343249ffc5cf`。

| 项目 | v1.0.0 | v1.1.0 |
|---|---|---|
| 验证数据 | 人工/随机向量和人工单任务样例 | 增加指定 KWT-1 真实样本的 12 层 HEX/NPZ |
| 软件校验 | 整数参考生成、单任务浮点 JSON 导出 | 增加 manifest/HEX 格式、独立整数重算、NPZ 和浮点量化复核 |
| 仿真入口 | 人工回归与单任务 | 增加按 manifest 编译一次、运行 12 层的双仿真器入口 |
| 构建与报告 | 各入口的固定仿真目录 | 真实数据每次建立独立运行编号，记录源码及数据哈希 |
| 故障检测 | TB 断言、结果检查、超时 | 增加 5 类数据损坏软件检查 |
| 硬件 | 串行 64 项 MAC | 两个 RTL 文件逐字节保持一致 |
| 交接证据 | 人工验证说明 | 增加真实数据逐层结果、原始文本日志和软件报告 |

## 兼容性

继续采用 signed 16 输入/权重、12 位小数，signed 40 偏置、24 位小数，40 位点积累加及 41 位加偏置结果；shift 支持 0–31，本批为 12。半值远离零、16 位饱和输出与 valid/ready 协议不变。

软件变化不意味着模型参数被写入 RTL，也没有加入完整矩阵缓存、权重 bank、CPU 或总线。12 层输入分别来自原浮点模型，不能视为量化结果在模型内连续传播。

## 证据与限制

软件、Icarus 和 XSim 各 12/12 通过；原 1103 组回归在两个仿真器中继续通过；5 类异常数据测试正确失败。全部真实 HEX 的校验值与输入交付包一致。

保留 `evidence` 中原运行记录；新克隆执行时生成自己的 `sim` 报告。完整 NPZ 随版本提供，以便严格复核选定元素，但并未对其中全部输出运行 RTL。大型音频、checkpoint、波形和仿真构建产物不纳入仓库。

v1.0.0 保持原样。新增版本目录、根 README 索引更新之外，不改变其他架构或协作者权限。
