软件 12 层、304128 个真实输出全部通过。真实矩阵、人工矩阵及 lane 数值检查分别统计；两个工具验证相同真实数据范围，不相加宣称更多独立真实输出。

每个输出在握手时写入 TB 的显式结果存储数组，并比较 total/result/saturated。任务结束后核对全部存储单元及坐标覆盖，再将原始 CSV 重建为 99×256 NPZ 独立比较。每次完整任务均确认 X SRAM 地址 4095/4096 已命中。

6 类故障为：偏置填充高位非法、输入文件缺失、HEX 截断、加载停止超时、错误参考、未初始化 SRAM 读取。测试只修改临时副本。取消 ARCH02_BEHAVIORAL 且没有真实适配器时，编译明确失败，未使用空壳宏冒充有效存储。

## 容量与周期

内部 SRAM 配置为 2×4096×16 + 8×128×16，共 **18 KiB**。实际用于 X 和当前权重块的数据为 13696 字节，另外使用偏置、累加和输出寄存器；内部宏面积尚未获取。

两套工具的全部真实层在无空拍/反压、读延迟1拍条件下，均得到：

| 分项 | 周期 |
|---|---:|
| 输入、权重、偏置装载 | 23488 |
| MAC 及启动/读流水线/转换控制 | 215424 |
| 25344 项结果写回 | 25344 |
| 总计 | **264256** |
| 其中有效8路MAC更新（计算分项的子集） | 202752 |

按150 MHz目标换算约1.7617 ms/层，但本次功能TB时钟为10 ns；该换算不证明150 MHz时序可达。计数覆盖独立接口上的加载至最后写回，尚未包含512 KB共享SRAM入库、E203调度和真实总线/宏成本，不能直接作为正式比赛性能。

随机空拍与反压作业的 load_wait/write_wait 及2拍延迟开销保存在 summary.json，等待是对应分项的子集。未报告未经真实库支持的面积、功耗或综合时序结论。
