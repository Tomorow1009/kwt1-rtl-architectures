# v2.0.0 修改与验证结果

## 相对 v1.3.0

- 从 TB 调度单个串行点积扩展为 8 个输出通道并行矩阵控制器，复用 dot64/requantize。
- 18 KiB 单缓冲：2×RAMSP4096X16 缓存 X，8×RAMSP128X16 缓存 8 列权重；32 组完成 99×256 输出。
- 增加加载流、bank/地址生成、输出行列坐标及反压保持；量化格式、舍入和饱和规则不变。
- 支持 behavioral、pin_mock、vendor 后端，1/2 拍 SRAM 接口。厂商底层宏直接命名端口例化，显式配置，无替代模型回退。

## 本次服务器修正

- 厂商 Q 在沿后 1 ns 更新；宏单测数据比较由同时间采样改为 +4 ns，有效标记仍在 +1 ns 检查。
- VCS runner 显式区分 timing 与 functional；functional 使用同一厂商模型中的 ARM_UD_MODEL。
- 增加实际库盘点、DC 约束、增量 hold 修复、独立审计脚本和交接文档。核心 MAC、转换及架构二调度 RTL 未因本次服务器调试而改变。

## 尚未通过或未验证

- 默认厂商 RTL 时序分支 r02 完整矩阵曾触发 0.5 ns hold 检查；本次功能分支通过不消除该历史失败，DC 修复也不代表已重跑该仿真。
- 带 SDF 门级仿真、形式等价、多 PVT/RC 角、CTS、布局布线后时序、功耗和最终面积验收尚未完成。现有正裕量极小。
- DC 使用理想时钟、暂定 IO 预算和复位 false path；实际系统预算、复位恢复/移除检查及同步释放待集成验证。
- E203/SoC、总线加载及真实写响应、端到端 KWT 推理、官方评测集逐层 NRMSE 与分类准确率未验证。
- 本次是单语音各层独立捕获输入的完整第一线性层矩阵，不是卷积，也不是全部语音识别成功。

详细原始报告路径、工具版本和告警见交接文档；完整报告留在服务器，仓库摘要来自现场观察。
